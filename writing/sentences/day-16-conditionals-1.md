# ⭐ SECTION A: THEORY & PATTERNS

## 🎯 What is Conditional 1?

**Conditional 1** = A real, possible situation in the future based on a condition that might happen.

| Element | Example | Meaning |
|---|---|---|
| **Condition (If-clause)** | If you **study hard** | = Something MIGHT happen (likely, real) |
| **Result (Main clause)** | you **will pass** | = This WILL happen as a consequence |
| **Logic** | **Real cause → Real effect** | = This is possible & realistic |

---

## 📋 FORM: If + Present → Will + Base

| **Pattern** | **Example** | **Structure** |
|---|---|---|
| Affirmative | **If** he comes, **will** you help him? | If + S + present simple, S + **will** + base verb |
| Negative (Cond) | **If** you **don't** prepare, you **won't** succeed | If + S + **don't/doesn't** + base, S + **won't** + base |
| Negative (Result) | **If** you study, you **won't** fail | If + S + present, S + **won't** + base |
| Question | **If** it rains, **will** you stay home? | If + S + present, **will** + S + base? |

---

## 🎓 When to Use Conditional 1

### ✅ USE Conditional 1 for:

1. **General truthful situations** (always true)
   - "If water reaches 100°C, it **will** boil" (scientific fact)

2. **Real, likely future events**
   - "If you arrive late, your boss **will** be angry" (probable)
   - "If she studies, she **will** pass the exam" (likely)

3. **Instructions & procedures**
   - "If you press the button, the door **will** open"
   - "If you cook the pasta for 10 mins, it **will** be soft"

4. **Promises & warnings**
   - "If you call me, I **will** help you" (promise)
   - "If you don't eat, you **will** get sick" (warning)

5. **Offers & conditions with "unless"**
   - "If you need money, I **will** lend you some" (offer)
   - "Unless you pay, they **will** cut the electricity" (condition)

### ❌ DON'T USE Conditional 1 for:

| Situation | Wrong | Right |
|---|---|---|
| Impossible/very unlikely | "If you visit Mars, you will..." | Conditional 2: "If you could visit..." |
| Hypothetical past | "If you studied yesterday, you would..." | Conditional 3: "If you had studied..." |
| General routine | "If I drink coffee, I wake up early" | Present Simple (no condition) |

---

## 🔄 Key Signal Words

| Signal | Example | Type |
|---|---|---|
| **If** | If the weather is nice, I **will** go out | Primary conditional marker |
| **Unless** = If not | Unless you hurry, you **will** be late | Negative condition |
| **As long as** = If | As long as you work hard, you **will** succeed | Condition (affirm) |
| **Provided that** = If | Provided you have a ticket, **will** they let you in? | Condition (formal) |
| **When** (= if certain) | When you finish, **will** you call me? | Used for certainties → sometimes Cond 1 |

---

## ⚠️ COMMON TRAP: Don't use "will" in If-clause!

| ❌ WRONG | ✅ RIGHT | Why? |
|---|---|---|
| If he **will come**, I **will** help | If he **comes**, I **will** help | **If-clause = Present simple only** |
| If you **will study**, you **will pass** | If you **study**, you **will** pass | Never "will" after "if" |
| If it **will rain**, we **won't go** | If it **rains**, we **won't** go | Future is already in "will won't" |

## 🎯 Key Takeaways (Memorize!)

1. **If-clause = Present Simple ONLY** (never "will")
2. **Result = Will + base verb** (or won't, would, etc.)
3. **Use Conditional 1 for real, likely future scenarios**
4. **"Unless" = "If not"** (always negative in meaning)
5. **When = Sometimes can replace if (for certainties)**
