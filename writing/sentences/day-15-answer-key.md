## Rule 1 Questions (For + duration → Perfect Continuous)

### Part 1 Q1 — Duration Signal

**Question:** "We _______ on the system upgrade **for two weeks now**, and we're making good progress."

**Answer:** b) **have been working**  
**Rule:** Rule 1 (For + duration, still ongoing)  
**Explanation:** "For two weeks now" = still happening → Perfect Continuous (have been + -ing)

---

### Part 1 Q2 — Duration in Dialogue

**Question:** **Q:** "How long _______ you _______ on debugging this API?"  
**A:** "I _______ on it **for 3 hours since** this morning."

**Answer:** b) **have / been working / have been working**  
**Rule:** Rule 1  
**Explanation:** "For 3 hours since this morning" = ongoing duration → Perfect Continuous for both blanks

---

### Part 1 Q3 — Since + Duration Phrase

**Question:** "The API _______ intermittently **since we deployed it last Tuesday**, and QA _______ bugs every day."

**Answer:** b) **has been failing / have been finding**  
**Rule:** Rule 1  
**Explanation:** "Since last Tuesday" + ongoing problem = Perfect Continuous for both (process emphasis)

---

## Rule 2 Questions (Specific time → Past Simple)

### Part 1 Q4 — Specific Past Time

**Question:** "I _______ the code review _______ **at 4 PM yesterday**, so it's ready for deployment today."

**Answer:** b) **completed / completed**  
**Rule:** Rule 2 (Specific time → Past Simple)  
**Explanation:** "Yesterday at 4 PM" = finished action in past → Past Simple

---

### Part 1 Q5 — Last + Time Period

**Question:** "The CI/CD pipeline _______ down **last Friday**, and the team _______ an incident report."

**Answer:** b) **went / wrote**  
**Rule:** Rule 2  
**Explanation:** "Last Friday" = specific past time → Past Simple

---

### Part 1 Q6 — Ago Signal

**Question:** "The server _______ **20 minutes ago**, and engineers _______ to fix it."

**Answer:** b) **crashed / have been trying**  
**Rule:** Rule 2 (for crashed) + Rule 1 (for have been trying)  
**Explanation:** "20 minutes ago" (specific) = Past Simple. "have been trying" = still ongoing effort → Perfect Continuous

## Rule 3 Questions (Two past events → Past Perfect)

### Part 1 Q7 — Before Signal with Two Past Events

**Question:** "By the time the QA team _______ the server **before** the afternoon meeting, the developers _______ three critical patches."

**Answer:** b) **had checked / had developed**  
**Rule:** Rule 3 (Past Perfect for event before another)  
**Explanation:** Two past events. First event (checking/developing) happened BEFORE the meeting → Past Perfect (had + -ed)

---

### Part 1 Q8 — By the time Signal

**Question:** "_______ the morning standup _______, the database migration _______ successfully."

**Answer:** b) **By the time / started / had completed**  
**Rule:** Rule 3  
**Explanation:** "By the time X happened, Y had already happened" = one before the other → Past Perfect

# PART 2 — Stative Verb Trap (Answer Key)

**Instructions:**
Show correct sentence, category, and why the wrong one is incorrect

---

### Part 2 Q1 — Emotion Verb (like/hate)

**Question:** Which is correct?

a) "I am liking the new project management tool."  
b) "I like the new project management tool."

**Correct:** b  
**Category:** Emotion (like)  
**Reason:** "Like" = stative verb (opinion/preference), NOT action. Never use continuous form. ❌ am liking / ✅ like

---

### Part 2 Q2 — Emotion Verb (hate)

**Question:** Which is correct?

a) "Our users are hating the slow load time."  
b) "Our users hate the slow load time."

**Correct:** b  
**Category:** Emotion (hate)  
**Reason:** "Hate" = stative (strong feeling). Use simple form. ❌ are hating / ✅ hate

---

### Part 2 Q3 — Thinking Verb (know)

**Question:** Which is correct?

a) "Do you know the password for the production server?"  
b) "Are you knowing the password for the production server?"

**Correct:** a  
**Category:** Thinking (know)  
**Reason:** "Know" = state of having information (stative). ❌ are knowing / ✅ know

---

### Part 2 Q4 — Thinking Verb (think = believe)

**Question:** Which is correct?

a) "I think we should deploy on Friday morning."  
b) "I am thinking we should deploy on Friday morning."

**Correct:** a  
**Category:** Thinking (think = believe/opinion)  
**Reason:** When "think" = belief/opinion, it's stative. When "think" = consider/focus, it can be continuous ("I'm thinking about..."). Here = opinion → simple form only.

---

### Part 2 Q5 — Dual Meaning: Think (Dynamic)

**Question:** Which is correct?

a) "I think about the new API architecture right now."  
b) "I am thinking about the new API architecture right now."

**Correct:** b  
**Category:** Thinking (think = focus/consider = DYNAMIC here)  
**Reason:** "Think about" = mental activity happening NOW → Continuous form. Compare: "I think (believe) it's good" (stative) vs "I'm thinking about it" (dynamic = considering).

---

### Part 2 Q6 — Perception: See

**Question:** Which is correct?

a) "I see the bug in line 47 of the code."  
b) "I am seeing the bug in line 47 of the code."

**Correct:** a  
**Category:** Perception (see)  
**Reason:** "See" = perceive/understand (stative). ❌ am seeing / ✅ see

---

### Part 2 Q7 — Perception: Seem/Appear

**Question:** Which is correct?

a) "The dashboard seems to have a memory leak."  
b) "The dashboard is seeming to have a memory leak."

**Correct:** a  
**Category:** Perception (seem = appear)  
**Reason:** "Seem/appear" = states of being perceived. Always stative. ❌ is seeming / ✅ seems

---

### Part 2 Q8 — Possession: Have (Stative)

**Question:** Which sentence is correct?

a) "We are having a server maintenance window scheduled for 8 PM."  
b) "We have a server maintenance window scheduled for 8 PM."

**Correct:** b  
**Category:** Possession (have)  
**Reason:** "Have" = own/possess (stative). ❌ are having / ✅ have  
*(Note: "we are having a meeting" is sometimes acceptable = "experiencing," but "have scheduled" = possession → simple)*

# PART 3 — SVA Trap (Answer Key)

**Instructions:**
Show subject, singular/plural decision, and correct verb

---

### Part 3 Q1 — The number of...

**Question:** "The number of developers _______ increased by 50% this quarter."

**Answer:** b) **is**  
**Subject:** "The number" (= singular concept)  
**Singular or Plural?** SINGULAR  
**Explanation:** "The number of" always takes **singular verb**, even though "developers" is plural.  
→ Xem Cheat Sheet: SVA Trap #1 — "The number" = singular

---

### Part 3 Q2 — A number of...

**Question:** "A number of applications _______ already received by HR, and they _______ being reviewed."

**Answer:** b) **have / are**  
**Subject:** "A number" = plural concept. "Applications" is the real plural focus.  
**Singular or Plural?** PLURAL  
**Explanation:** "A number of" = **plural verb**  
→ Xem Cheat Sheet: SVA Trap #2 — "A number of" = plural

---

### Part 3 Q3 — Either...or (with mixed subjects)

**Question:** "Either the frontend team or the backend developers _______ required to submit the code review **by Friday**."

**Answer:** b) **are**  
**Subject:** Verb agrees with the **NEAREST** noun: "developers" (plural)  
**Singular or Plural?** PLURAL (depends on nearest)  
**Explanation:** Either...or → agree with closest noun  
→ Xem Cheat Sheet: SVA Trap #3 — "Either...or" → nearest noun

---

### Part 3 Q4 — Neither...nor (with mixed subjects)

**Question:** "Neither the project manager nor the QA engineers _______ informed about the security vulnerability **until this morning**."

**Answer:** b) **were**  
**Subject:** Verb agrees with **NEAREST**: "engineers" (plural)  
**Singular or Plural?** PLURAL (depends on nearest)  
**Explanation:** Neither...nor → nearest verb agreement  
→ Xem Cheat Sheet: SVA Trap #4 — "Neither...nor" → nearest noun

---

### Part 3 Q5 — One of the...

**Question:** "One of the senior engineers _______ developed the original microservices architecture for our platform."

**Answer:** b) **has**  
**Subject:** "One" (= always singular, not "engineers")  
**Singular or Plural?** SINGULAR  
**Explanation:** "One of the..." → singular verb  
→ Xem Cheat Sheet: SVA Trap #5 — "One of the" = singular

---

### Part 3 Q6 — Police (Exception)

**Question:** "The police _______ investigating the data breach that occurred **last week**, and they _______ found 3 entry points."

**Answer:** b) **are / have**  
**Subject:** "Police" (= always plural like "people," "staff")  
**Singular or Plural?** PLURAL (always)  
**Explanation:** Police exception → always plural verb  
→ Xem Cheat Sheet: SVA Trap #6 — "Police" = always plural

# PART 4 — Mixed Paragraph Correction (Answer Key)

---

## Paragraph 1: Project Kickoff

**Original paragraph:** "Our team have been tasked with building a mobile banking app, and we are already starting the architecture phase. The number of requirements are growing every day — yesterday we received 15 new feature requests, and we are thinking about how to prioritize them. Since Monday, the design team has been working for implementing the new UI framework, and they are having difficulty with the responsive layout. One of my senior developers has wrote 3 design pattern documents already, and he seems really excited to move forward."

---

### Part 4 Paragraph 1 Answer Key

| Error # | Location | ❌ Wrong | ✅ Correct | Rule Violated | Why? |
|---------|----------|---------|-----------|---|---|
| **1** | "Our team **have been tasked**" | have been | **has been** | SVA | "Team" = singular collective noun (American English standard). Should be "The team **has** been..." |
| **2** | "we **are already starting** the architecture" | are starting | **have already started** | Tense/Signal | "Already" signals Perfect Simple (completion). Change to "**have already started**" (result focus) OR remove "already" if ongoing. |
| **3** | "The number of requirements **are growing**" | are | **is** | SVA | "The number of" = singular. Rule: "The number" always singular verb. Should be "**The number of requirements is growing**" |
| **4** | "One of my senior developers **has wrote**" | has wrote | **has written** | Irregular Past Participle | Past participle of "write" = "written," not "wrote". Should be "**has written**" |

---

**Corrections Summary:**
1. ❌ "Our team have" → ✅ "Our team **has**"
2. ❌ "are already starting" → ✅ "have already **started**"
3. ❌ "The number...are" → ✅ "The number...is"
4. ❌ "has wrote" → ✅ "**has written**"

---

## Paragraph 2: Sprint Review Crisis

**Original paragraph:** "We discovered 47 bugs in testing last Tuesday when the QA team has been running regression tests. Since then, we are fixing the issues every day, and I have been noticing suspicious behavior in the login API for three days. The number of critical bugs are 12, and neither the backend team nor the frontend developers is willing to work overtime without compensation. A number of stakeholders have complained about the delays, but they are not understanding the complexity of the security implications involved."

---

### Part 4 Paragraph 2 Answer Key

| Error # | Location | ❌ Wrong | ✅ Correct | Rule Violated | Why? |
|---------|----------|---------|-----------|---|---|
| **1** | "last Tuesday **when** the QA team **has been running**" | has been running | **was running** | Tense & Signal | "Last Tuesday" = specific past time (Rule 2). Should use Past Simple. "Was running" shows what was happening at that moment. |
| **2** | "they **are not understanding** the complexity" | are not understanding | **don't understand** | Stative Verb | "Understand" = mental state (stative verb). "Understand the complexity" = grasp/comprehend. Can't use continuous. Simple form only. |
| **3** | "The number of critical bugs **are** 12" | are | **is** | SVA | "The number of bugs" = singular. Rule: "The number" = singular verb. Should be "**is 12**" |
| **4** | "neither...nor the frontend developers **is**" | is | **are** | SVA | "Neither...or" verb agrees with NEAREST noun. Nearest = "developers" (plural) → should be "**are**" (not "is"). |

---

**Corrections Summary:**
1. ❌ "last Tuesday when...has been running" → ✅ "last Tuesday when...was running"
2. ❌ "are not understanding" → ✅ "**don't understand**"
3. ❌ "The number...are 12" → ✅ "The number...**is 12**"
4. ❌ "nor the developers **is**" → ✅ "nor the developers **are**"

# PART 5 — Cheat Sheet Reasoning Check (Answer Key)

---

### Part 5 Q1 — Reasoning Test (Incorrect)

**Question:** "We have been testing the platform for 2 weeks, and we've found 23 bugs."

**Student's reasoning:** "I see 'for 2 weeks' → that's Perfect Continuous for the whole sentence."

**Is CORRECT or WRONG?** ❌ **WRONG**

**Explanation:**
- ✅ Part 1 correct: "For 2 weeks" + ongoing → Perfect Continuous "have been testing" ✓
- ❌ Part 2 wrong: "Found 23 bugs" = **countable result** (Rule 4) → Perfect Simple "have found"
- **Correct reasoning:** "For 2 weeks" = Rule 1 (Continuous), BUT "23 bugs" = Rule 4 (Simple). Two different rules in same sentence = TWO different tenses!
- → Xem Cheat Sheet: Có thể mix Perfect Continuous + Perfect Simple trong cùng câu nếu signal words khác nhau

---

### Part 5 Q2 — Reasoning Test (Correct)

**Question:** "I completed the code review at 3 PM yesterday."

**Student's reasoning:** "I see 'yesterday at 3 PM' → specific past time → Rule 2 → Past Simple 'completed'"

**Is CORRECT or WRONG?** ✅ **CORRECT**

**Explanation:**
- ✅ Perfect! "Yesterday at 3 PM" = specific past moment (Rule 2) → Past Simple "completed"
- → Xem Cheat Sheet: Rule 2 — Specific time → Past Simple

---

### Part 5 Q3 — Reasoning Test (Incorrect)

**Question:** "The number of critical issues has increased, and they have been causing slowdowns for months."

**Student's reasoning:** "I see plural 'issues' and 'have been' → that's plural continuing action → Present Perfect Continuous"

**Is CORRECT or WRONG?** ❌ **WRONG**

**Explanation:**
- ❌ Trap! Student looked at "issues" (plural), not the subject.
- **Correct subject:** "The number" (singular!) → "**has** increased"
- **Correct reasoning:** 
  1. Subject = "The number" (singular, not "issues") → "**has**" (not "have")
  2. Signal = "for months" (duration) → Perfect Continuous is correct for part 2
  3. Sentence should be: "The number of critical issues **has** increased, and they **have been** causing slowdowns for months"
- → Xem Cheat Sheet: SVA Trap #1 — Focus on the MAIN SUBJECT, not the noun after "of"

---

### Part 5 Q4 — Reasoning Test (Partially Incorrect)

**Question:** "I've sent 12 emails since Monday, and the team is understanding the new requirements."

**Student's reasoning:** "I see '12 emails' + 'since Monday' → Perfect Simple. And 'is understanding' = continuous state → that's correct too."

**Is CORRECT or WRONG?** ❌ **WRONG**

**Explanation:**
- ✅ Correct for part 1: "12 emails" = countable (Rule 4) → Perfect Simple "have sent" ✓
- ❌ WRONG for part 2: "is understanding" = **stative verb trap**
  - "Understand" = mental state (stative verb, like know/think/believe)
  - Never use continuous form
  - Should be "**understand**" (simple), not "are understanding"
- **Correct reasoning:** "Understand" = stative (Thinking category) → simple form only ❌ is understanding / ✅ understand
- → Xem Cheat Sheet: Stative Verbs — "Understand" category = Thinking (never continuous)

---

### Part 5 Q5 — Reasoning Test (Correct)

**Question:** "By the time the deployment finishes, our team will have worked for 18 hours straight."

**Student's reasoning:** "I see 'by the time' → two time points. The deployment finishing is ONE, working 18 hours is ANOTHER = two events. 'will have worked' = Future Perfect → event completes by that moment"

**Is CORRECT or WRONG?** ✅ **CORRECT**

**Explanation:**
- ✅ Excellent! "By the time" = signal for chronological relationship (Rule 3 variant for future)
- ✅ TWO time points: (1) Deployment finishes, (2) Team finishes working → "will have worked" shows completion BEFORE deployment
- ✅ "Will have worked" = Future Perfect (future version of Rule 3)
- → Xem Cheat Sheet: Rule 3 signal "by the time" extends to Future Perfect too
